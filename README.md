# Win98 Bookmarks Desktop

[![CI](https://github.com/hermanguilliman/wind98-newtab/actions/workflows/ci.yml/badge.svg)](https://github.com/hermanguilliman/wind98-newtab/actions/workflows/ci.yml)

Chrome-расширение, которое заменяет пустую новую вкладку на «рабочий стол»
Windows 98.

Ваши закладки и папки из Chrome отображаются на нём значками: папка открывается
окном «Проводника» с историей переходов, закладка — сайтом. В трее живут часы,
погода и календарь, в меню «Пуск» — настройки, поиск, блокнот и калькулятор.

- **Один файл для Chrome** — готовый IIFE-скрипт, никакой сборки на клиенте.
- **Без аналитики и аккаунтов** — закладки читаются локально через `chrome.bookmarks`.
- **Живая синхронизация** — новая, переименованная или удалённая закладка сразу появляется на рабочем столе и в открытых окнах.
- **Настраивается** — обои, размер и стиль иконок, темы, режим клика, панель задач.

## Возможности

### Рабочий стол и закладки

- Классический рабочий стол Win98: цвет `#008080`, значки с прозрачными подписями и тенью.
- Все корневые группы закладок (панель, «Другие», «Мобильные») — с разделителями, в фиксированном порядке.
- **Папки как в оригинале**: стиль «классический» — попиксельная копия золотой папки из `shell32.dll` (закрытая — 256-цветная 48×48, открытая — с синим листом). Есть альтернативы: «объёмные» и «с контуром».
- Иконки закладок — favicon'ки сайтов через Google Favicons, с очисткой белого фона, чтобы они не выпадали из обоев.
- Навигация по ярлыкам с клавиатуры и выделение рамкой (marquee) мышью.

### Окна

- Окна можно двигать, разворачивать, сворачивать и менять размер (правый нижний угол).
- Папки открываются **в одном окне**: вложенная папка открывается на месте, «Назад» возвращается по истории, «Вверх» — в родительскую папку (из корневой — в «Все закладки»).
- Панель инструментов окна: «Назад», «Вверх», «Обновить», переключатель «Вид: значки / список».
- Панель задач: кнопка «Пуск», кнопки открытых окон, «Свернуть все», контекстное меню («Каскад окон», «Стопкой», «Свойства панели задач»).
- Окно «Все закладки» (меню «Пуск» → «Открыть все закладки») — обзор всех корневых групп в одном браузере.

### Контекстное меню и операции

- По ярлыку: открыть, в новой вкладке, в фоновой вкладке, в новом окне, в режиме инкогнито, копировать адрес, переименовать, удалить, «Свойства».
- «Свойства» (`Alt+Enter`): тип, адрес, расположение в дереве, содержимое, дата добавления, идентификатор.
- По рабочему столу: «Обновить», «Создать папку», «Вставить» (адрес из буфера), «Открыть все закладки», «Настройки».
- Перенос закладок и папок перетаскиванием внутри окна папки: в другую папку или между соседними элементами.

### Приложения в трее и меню «Пуск»

- **Календарь** (клик по часам): месячная сетка с государственными праздниками и выходными России (данные `isdayoff.ru`, кэш в хранилище, встроенное правило по ст. 112 ТК как запасной вариант) и свои события — «весь день» или время, диапазон дат, заметка.
- **Погода**: иконка и температура в трее; двойной клик — подробное окно (ощущается как, влажность, ветер, осадки, восход/закат). Источник — Open-Meteo без API-ключа; если он недоступен, используется met.no (Yr).
- **Блокнот** (кнопка на панели задач): заметки с автосохранением.
- **Калькулятор** (меню «Пуск» → «Программы»).
- **Поиск по закладкам** (`Ctrl+F`): мгновенная фильтрация по имени, адресу и пути, навигация стрелками, открытие по Enter.
- Пасхалка: 10 кликов по часам открывают окно с сообщением.

## Установка

1. Откройте `chrome://extensions/`.
2. Включите «Режим разработчика» (Developer mode).
3. Нажмите «Загрузить распакованное расширение» (Load unpacked).
4. Выберите папку `win98-newtab`.
5. Откройте новую вкладку — загрузится «рабочий стол».

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+F` | Поиск по закладкам |
| `←` `→` `↑` `↓` | Перемещение выделения по ярлыкам |
| `Enter` | Открыть выделенный ярлык |
| `Alt+Enter` | Свойства выделенного ярлыка |
| `Delete` | Удалить выделенный ярлык |
| `Ctrl+C` | Скопировать адрес выделенной закладки |
| `Esc` | Закрыть меню или диалог |

## Настройки

Меню «Пуск» → «Настройки». Настройки разбиты на вкладки, чтобы не перегружать окно:

- **Обои** — цвет фона, изображение с компьютера или по URL (скачанные картинки хранятся локально), расположение: замостить / растянуть / по центру, масштаб. Живой предпросмотр; окно не закроется, пока не выбрано и не скачано изображение.
- **Поведение** — режим открытия (один или двойной клик), часы (показывать дату и/или день недели), город для погоды в трее.
- **Вид** — размер иконок (24/32/48 px), стиль иконок папок (классические / объёмные / с контуром), тени для подписей значков, размер текста, расстояние между иконками и отступы рабочего стола. Всё с быстрым предпросмотром.
- **О системе** — название, версия, краткое описание, сведения о системе (браузер, количество закладок и папок, занятый объём хранилища) и данные автора.

## Права доступа и конфиденциальность

Расширение запрашивает минимум:

- **`bookmarks`** — чтение дерева закладок и операции с ними (создание, переименование, перемещение, удаление).
- **`storage`** + **`unlimitedStorage`** — настройки, свои события календаря, обои и кэш favicon'ок.
- **`host_permissions`** — `api.open-meteo.com` и `geocoding-api.open-meteo.com` (погода), `api.met.no` (запасной источник погоды), `*.gstatic.com` (favicon'ки), `isdayoff.ru` (праздники).

Настройки и события календаря хранятся в `chrome.storage.sync` и потому
синхронизируются между устройствами через аккаунт Google. Всё остальное
(обои, кэш favicon'ок, кэш погоды и праздников, раскладка окон, заметки)
живёт в `chrome.storage.local` и никуда не отправляется.

## Структура проекта

| Путь | Назначение |
|------|------------|
| `win98-newtab/` | Само расширение — единственная часть, загружаемая в Chrome. |
| `src/` | Исходники (собираются в `win98-newtab/newtab.js`). |
| `tests/` | Unit-тесты чистой логики (vitest). |
| `scripts/build.mjs` | Сборка esbuild + автоматический cache-bust. |
| `tsconfig.json`, `tsconfig.lib.json` | Два прохода проверки типов. |
| `AGENTS.md` | Инструкции для ИИ-агентов: сборка, проверки, архитектура, конвенции. |
| `.github/workflows/ci.yml` | CI: typecheck + тесты + сборка + проверка артефакта. |

### Файлы расширения

| Файл | Назначение |
|------|------------|
| `win98-newtab/manifest.json` | Манифест Manifest V3: переопределение новой вкладки, права, иконки. |
| `win98-newtab/newtab.html` | HTML рабочего стола; подключает `win98.css` и `newtab.js` с `?v=<hash>` (короткий SHA-256 каждого файла вставляет `scripts/build.mjs`). |
| `win98-newtab/newtab.js` | Собранный скрипт (IIFE) — вся логика приложения. Редактируется только через сборку. |
| `win98-newtab/win98.css` | Вся стилизация Windows 98: фаски outset/inset, палитра на CSS-переменных `--win98-*`. |
| `win98-newtab/icons/` | Иконки интерфейса (`start.png`, `pc_icon.png`, `settings.png`, …). Иконки закладок и папок генерируются на `canvas` или берутся из Google Favicons. |

## Разработка

Требуется Node.js 22+.

```powershell
npm install
npm run build        # esbuild: src/ -> win98-newtab/newtab.js
npm run verify       # typecheck x2 + vitest + build + node --check
npm test             # только unit-тесты чистой логики
```

### Устройство исходников

```
src/
  app.js          оркестратор: восстановление окон, слоты, init()
  state.js        синглтон state + findNodeById()
  constants.js    именованные константы
  types.d.ts      канонические JSDoc-typedef'ы
  ui/             модули интерфейса (окна, диалоги, настройки, погода,
                  календарь, поиск, блокнот, калькулятор, рабочий стол,
                  папки, drag&drop, операции с закладками, события, live-sync)
  lib/*.ts        чистая логика без DOM и chrome.* (тема, настройки, закладки,
                  поиск, форматирование, окна, календарь, праздники)
```

Chrome видит только собранный `win98-newtab/newtab.js` — модули и TypeScript
не попадают в расширение. Ручная правка артефакта запрещена: меняйте исходники
в `src/` и пересобирайте.

После правок перезагрузите расширение в `chrome://extensions/` и откройте новую
вкладку. Расширение работает только в контексте новой вкладки; при первом
обращении к закладкам Chrome запросит соответствующее разрешение.

Подробности — в [AGENTS.md](AGENTS.md).
