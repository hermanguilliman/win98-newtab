# Win98 Bookmarks Desktop (Chrome Extension)

Заменяет пустую страницу новой вкладки Google Chrome на «рабочий стол» в стиле Windows 98.

На рабочем столе отображаются все **папки** и **закладки** из закладок Chrome
(панель закладок, другие закладки, мобильные закладки) в виде иконок рабочего стола
(ярлыков). Двойной клик по папке открывает окно «Проводника» Win98 с содержимым;
двойной клик по закладке открывает сайт.

## Возможности

- 🖥️ Классический рабочий стол Win98 (цвет `#008080`).
- 📁 Папки и закладки отображаются как иконки рабочего стола.
- 🗂️ **Иконки папок как в оригинальной Win98** — «классический» стиль это точная
  попиксельная копия золотой папки из `shell32.dll` (закрытая — 256-цветная 48×48,
  открытая — с синим листом). Есть и альтернативные стили (объёмные / с контуром),
  выбираются в Настройки → Вид, вступают в силу сразу.
- 🔄 **Живая синхронизация** — добавленные/удалённые/переименованные закладки сразу
  появляются на рабочем столе и в открытых окнах папок, без перезагрузки вкладки.
- 🔍 **Поиск по закладкам** (меню «Пуск» → «Поиск» или `Ctrl+F`) — мгновенная
  фильтрация по имени, адресу и пути, навигация стрелками, открытие по Enter.
- 📂 Папки открываются в отдельных окнах с панелью инструментов («Назад», «Вверх»,
  кнопка переключения **вид значков / список**) и строкой состояния. Навигация по
  закладкам — **в одном окне**: вложенная папка открывается в том же окне, «Назад»
  возвращается по истории, «Вверх» — в родительскую папку (в корневой папке —
  к списку «Все закладки»). «Вверх» неактивен на верхнем уровне (у него нет
  предыдущего уровня), «Назад» — когда история пуста. Окно «Все закладки» (меню
  «Пуск» → «Открыть все закладки») работает как такой же браузер.
- 📋 Контекстное меню (правый клик): открыть / в новой вкладке / в фоновой вкладке /
  в новом окне / в режиме инкогнито / копировать адрес / переименовать / удалить /
  **Свойства**.
- ℹ️ **Свойства** (ПКМ → «Свойства» или `Alt+Enter`): тип, адрес, расположение
  в дереве, содержимое, **дата добавления** (`dateAdded`), идентификатор.
- 📅 **Календарь** — клик по часам в трее открывает календарь с навигацией ◀ ▶,
  кнопкой «Сегодня» и панелью выбранного дня. **Государственные праздники и
  выходные России**: статус дня загружается с `isdayoff.ru` (кэшируется в
  `chrome.storage.local`), при офлайне/ещё не опубликованных годах срабатывает
  встроенное правило ст. 112 ТК (праздник = нерабочий день, выпавший на
  выходные — переносится на следующий рабочий день). Праздничные дни выделены
  в гриде и в панели дня. **Свои события**: название, «весь день» или время
  начала/окончания, даты начала и окончания (диапазон), заметка; события
  отмечены счётчиками в сетке (подробности — в панели дня) с созданием,
  редактированием и удалением в диалоге на манер Android-календарей. События
  и настройки хранятся в `chrome.storage.sync` (синхронизируются между
  устройствами через аккаунт Google; настройки загружаются из sync при
  каждом открытии вкладки).
- ⌨️ Навигация с клавиатуры: стрелки перемещают выделение по ярлыкам, Enter открывает,
  `Delete` удаляет, `Alt+Enter` — свойства, `Ctrl+C` копирует адрес.
- 🖱️ Средняя кнопка мыши по закладке открывает её в фоновой (неактивной) вкладке
  Chrome; по папке — ничего не делает.
- 🖱️ **ПКМ по рабочему столу**: «Обновить», «Создать папку», «Вставить» (URL из
  скопированного адреса), «Открыть все закладки», «Настройки».
- 🗔 Окна можно двигать, разворачивать, сворачивать и изменять размер (перетаскивая
  правый нижний угол).
- 🧾 Панель задач с кнопкой «Пуск», кнопками открытых окон, системным треем с часами
  и погодой (иконка + температура, город настраивается). **Двойной клик по погоде**
  открывает окно с подробными данными (ощущается как, влажность, ветер, осадки,
  восход/закат) — от Open-Meteo, без API-ключа.
- ⏱️ Вертикальный «Windows98» в меню «Пуск».
- 🎁 **Пасхалка**: 10 кликов по часам в панели задач открывают окно с сообщением.
- ⚙️ Настройки (меню «Пуск» → «Настройки») — разделены на вкладки, чтобы не
  перегружать окно:
  - **Обои** — цвет фона, изображение с компьютера или по URL (скачанные картинки
    хранятся локально в `chrome.storage.local`), с настройкой расположения
    (замостить / растянуть / по центру) и живым предпросмотром. Окно не
    закрывается, если выбрано изображение, но оно не выбрано/не скачано.
  - **Поведение** — режим открытия (один/двойной клик), часы (показывать дату и/или
    день недели рядом со временем) и город для погоды в панели задач (иконка +
    температура рядом с часами; данные — Open-Meteo, без API-ключа).
  - **Вид** — размер иконок (мелкие / средние / крупные, 24/32/48 px), стиль
    иконок папок (классические / объёмные / с контуром), тени для подписей
    значков на рабочем столе (как одноимённая опция «Эффекты» в оригинальной
    Win98 — подписи всегда прозрачные, сквозь них видно обои/цвет рабочего
    стола), размер текста, расстояние между иконками и отступы рабочего стола
    (сверху/снизу и слева/справа) — всё с быстрым предпросмотром.
  - **О системе** — название, краткое описание расширения и данные автора.

## Установка (Developer Mode)

1. Откройте `chrome://extensions/`.
2. Включите «Режим разработчика» (Developer mode).
3. Нажмите «Загрузить распакованное расширение» (Load unpacked).
4. Выберите папку `win98-newtab`.
5. Откройте новую вкладку — загрузится «рабочий стол».

## Разработка

Расширение собирается из исходников в `src/` в единый скрипт `win98-newtab/newtab.js`
(cкриптом `npm run build`, esbuild, формат IIFE). Chrome ничего не знает про
модули/TypeScript — `newtab.html` подключает `newtab.js` и `win98.css` с
автоматическим cache-bust `?v=<hash>`. Ручная правка собранного `newtab.js`
запрещена — меняйте источники в `src/` и пересобирайте.

Проверка перед коммитом:

```powershell
npm run verify        # typecheck ×2 + vitest-тесты + build + node --check
```

- `src/app.js` — оркестратор (инициализация, события рабочего стола, горячие клавиши,
  live-sync закладок), `src/ui/*.js` — модули интерфейса (окна, диалоги, настройки,
  погода, календарь, поиск, блокнот, калькулятор, иконки рабочего стола, папки,
  drag&drop, операции с закладками), `src/state.js` — общее состояние.
- Чистые lib-модули в `src/lib/*.ts` покрываются unit-тестами `npm test`;
  поведение с DOM/chrome.* проверяется headless-проверкой `win98-smoke.cjs`
  (см. AGENTS.md).
- Перезагрузите расширение в `chrome://extensions/` и откройте новую вкладку.
- Расширение работает только в контексте новой вкладки; для проверки навигации и
  открытия закладок Chrome запросит права на закладки.

## Права доступа

Расширению нужны права на **закладки** (`"bookmarks"`) и локальное **хранилище**
(`"storage"` + `"unlimitedStorage"` для хранения обоев). Значки сайтов подгружаются
сервисом Google Favicons (faviconV2) по домену. Доступ к погоде — `host_permissions`
для `api.open-meteo.com` и `geocoding-api.open-meteo.com`, к российскому календарю —
для `isdayoff.ru`. Данные не покидают браузер — всё отображается локально.
